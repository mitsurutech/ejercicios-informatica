# Clases y objetos: ejercicio `bebidas-del-bar`

> **Lección:** Clases y objetos, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

La clase Drink ya está escrita. Completa los cuatro métodos. El primero crea una bebida con new y rellena sus atributos. El segundo baja el precio de una bebida que ya existe. El tercero dice cuál es más barata. El cuarto escribe un texto.

## Archivos de partida

- `Main.java`

Escribe tu respuesta en `Main.java`. Para probarla, ejecuta `javac Main.java` y después `java Main`.
