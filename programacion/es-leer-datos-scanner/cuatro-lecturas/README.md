# Leer datos del teclado: ejercicio `cuatro-lecturas`

> **Lección:** Leer datos del teclado, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Cada método recibe un Scanner y tiene que leer de él. El primero suma dos números. El segundo lee un nombre y devuelve el saludo. El tercero lee las entradas y el precio, y devuelve el total. En el cuarto, la edad está en una línea y el nombre en la siguiente: cuidado con el salto de línea.

## Archivos de partida

- `Main.java`

Escribe tu respuesta en `Main.java`. Para probarla, ejecuta `javac Main.java` y después `java Main`.
