# Decidir con if y else: ejercicio `cuatro-decisiones`

> **Lección:** Decidir con if y else, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Completa los cuatro métodos con if y else. El primero da la nota con palabras. El segundo devuelve el mayor de dos números. El tercero decide el precio del envío de una compra: gratis desde 50 euros. El cuarto dice si un número es positivo, negativo o cero. Cuidado con los límites: 5, 7, 9 y 50 cuentan.

## Archivos de partida

- `Main.java`

Escribe tu respuesta en `Main.java`. Para probarla, ejecuta `javac Main.java` y después `java Main`.
