# Bucles dentro de bucles: ejercicio `figuras-y-partidos`

> **Lección:** Bucles dentro de bucles, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Completa los cuatro métodos con dos bucles. Los tres primeros devuelven una figura como texto: cada fila acaba con un salto de línea, que en Java se escribe \n. El cuarto cuenta los partidos de una liga: cada pareja de equipos juega una vez.

## Archivos de partida

- `Main.java`

Escribe tu respuesta en `Main.java`. Para probarla, ejecuta `javac Main.java` y después `java Main`.
