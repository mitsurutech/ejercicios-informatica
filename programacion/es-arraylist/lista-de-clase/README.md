# ArrayList: listas que crecen: ejercicio `lista-de-clase`

> **Lección:** ArrayList: listas que crecen, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Trabaja con la lista de nombres de una clase. addIfMissing añade un nombre solo si no está. removeShort borra los nombres demasiado cortos y dice cuántos ha borrado. longest devuelve el nombre más largo. reversed devuelve una lista nueva al revés.

## Archivos de partida

- `Main.java`

Escribe tu respuesta en `Main.java`. Para probarla, ejecuta `javac Main.java` y después `java Main`.
