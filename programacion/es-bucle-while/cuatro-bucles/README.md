# Repetir con while: ejercicio `cuatro-bucles`

> **Lección:** Repetir con while, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Completa los cuatro métodos con while. El primero suma los números del 1 al n. El segundo cuenta las cifras de un número: quitar la última cifra es dividir entre 10. El tercero calcula cuántos autobuses hacen falta para una excursión: ve restando plazas. El cuarto escribe una cuenta atrás como 3-2-1. Cuidado de que ningún bucle sea infinito.

## Archivos de partida

- `Main.java`

Escribe tu respuesta en `Main.java`. Para probarla, ejecuta `javac Main.java` y después `java Main`.
