# Un método, muchas formas: ejercicio `entradas-de-cine`

> **Lección:** Un método, muchas formas, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Ticket es una entrada normal de 10.0 euros. ChildTicket y StudentTicket heredan de ella. Sobrescribe price y label en cada una con los valores que dicen los comentarios. Después completa total, que suma el precio de un array de entradas mezcladas.

## Archivos de partida

- `Main.java`

Escribe tu respuesta en `Main.java`. Para probarla, ejecuta `javac Main.java` y después `java Main`.
