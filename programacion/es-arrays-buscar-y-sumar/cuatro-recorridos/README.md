# Buscar y sumar en un array: ejercicio `cuatro-recorridos`

> **Lección:** Buscar y sumar en un array, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Completa los cuatro métodos. El primero suma todos los números. El segundo devuelve el mayor. El tercero calcula la media y devuelve 0.0 si el array está vacío: cuidado con dividir entre cero. El cuarto busca un número y devuelve su posición, o -1 si no está.

## Archivos de partida

- `Main.java`

Escribe tu respuesta en `Main.java`. Para probarla, ejecuta `javac Main.java` y después `java Main`.
