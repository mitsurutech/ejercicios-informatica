# Cuando algo sale mal: ejercicio `cuatro-casos`

> **Lección:** Cuando algo sale mal, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Completa los cuatro métodos. parseAge convierte un texto en una edad y devuelve -1 si no vale. splitBill reparte euros entre personas y lanza una IllegalArgumentException si no hay personas. safeGet lee un puesto del array y devuelve un valor de repuesto si no existe. sumNumbers suma los textos que son números y se salta los demás.

## Archivos de partida

- `Main.java`

Escribe tu respuesta en `Main.java`. Para probarla, ejecuta `javac Main.java` y después `java Main`.
