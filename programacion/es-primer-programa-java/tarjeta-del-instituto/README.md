# Tu primer programa en Java: ejercicio `tarjeta-del-instituto`

> **Lección:** Tu primer programa en Java, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Escribe dos trozos de programa. El primero escribe tres líneas: Instituto Sol, Curso: primero y ¡Bienvenido!. El segundo escribe una línea: Hasta mañana. Los textos tienen que ser iguales a los del enunciado. Ahora solo tienes que rellenar lo que va entre las llaves.

## Archivos de partida

- `Main.java`

Escribe tu respuesta en `Main.java`. Para probarla, ejecuta `javac Main.java` y después `java Main`.

## ¿Te has atascado?

Mira la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es): cada lección explica la idea antes de dejarte probar.

## Que corrijan tu trabajo

Aquí no hay solución ni prueba, a propósito. En la [plataforma de aprendizaje MitsuruTech](https://mitsurutech.co.uk/es/learning), un profesor puede poner este ejercicio a una clase y corregirlo. Una cuenta de centro es [gratis el primer año](https://mitsurutech.co.uk/es/pricing) para hasta 50 estudiantes.
