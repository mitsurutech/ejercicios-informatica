# Métodos: trozos de programa: ejercicio `cuatro-metodos`

> **Lección:** Métodos: trozos de programa, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Escribe lo que falta en cuatro métodos. El primero calcula un precio con descuento. El segundo devuelve el mayor de dos números. El tercero dice si un número es par: un número es par si al dividirlo entre 2 sobra 0. El cuarto repite un texto varias veces.

## Archivos de partida

- `Main.java`

Escribe tu respuesta en `Main.java`. Para probarla, ejecuta `javac Main.java` y después `java Main`.
