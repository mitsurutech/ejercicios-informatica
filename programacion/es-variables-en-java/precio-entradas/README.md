# Variables en Java: ejercicio `precio-entradas`

> **Lección:** Variables en Java, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Vas a comprar entradas para un concierto. Cada entrada cuesta 2,50 euros. Completa los tres métodos. El primero calcula el precio de un grupo. El segundo dice si una persona es menor: menos de 18 años es menor. El tercero une "Hola, " con un nombre.

## Archivos de partida

- `Main.java`

Escribe tu respuesta en `Main.java`. Para probarla, ejecuta `javac Main.java` y después `java Main`.
