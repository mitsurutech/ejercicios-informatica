# Trabajar con texto: ejercicio `correo-y-clave`

> **Lección:** Trabajar con texto, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Completa los cuatro métodos. El primero crea el correo del instituto, todo en minúsculas. El segundo saca las iniciales en mayúsculas, como M.R. El tercero dice si una contraseña es fuerte: 8 caracteres o más. El cuarto dice si dos usuarios son el mismo sin fijarse en las mayúsculas.

## Archivos de partida

- `Main.java`

Escribe tu respuesta en `Main.java`. Para probarla, ejecuta `javac Main.java` y después `java Main`.
