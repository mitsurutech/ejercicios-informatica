## Qué hay que hacer

La clase Room es una sala de cine con aforo. Completa los tres métodos. freeSeats dice cuántas plazas quedan. enter deja entrar a un grupo solo si caben todos. leave hace salir gente y nunca deja menos de cero personas dentro.

## Archivos de partida

- `Main.java`

Escribe tu respuesta en `Main.java`. Para probarla, ejecuta `javac Main.java` y después `java Main`.
