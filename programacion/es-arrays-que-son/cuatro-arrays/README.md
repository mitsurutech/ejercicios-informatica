# Arrays: listas de valores: ejercicio `cuatro-arrays`

> **Lección:** Arrays: listas de valores, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Completa los cuatro métodos. El primero devuelve el último número de un array. El segundo une textos con una coma y un espacio, sin coma al final. El tercero devuelve un array nuevo con cada número multiplicado por 2, sin cambiar el original. El cuarto devuelve un array nuevo con los números al revés.

## Archivos de partida

- `Main.java`

Escribe tu respuesta en `Main.java`. Para probarla, ejecuta `javac Main.java` y después `java Main`.
