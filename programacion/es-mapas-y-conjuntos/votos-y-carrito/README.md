# Mapas y conjuntos: ejercicio `votos-y-carrito`

> **Lección:** Mapas y conjuntos, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Completa los cuatro métodos. countWords cuenta cuántas veces sale cada palabra y devuelve un mapa. uniqueCount cuenta los nombres distintos con un HashSet. cartTotal calcula el total de un carrito: unidades por precio de cada producto. Un producto sin precio no suma nada. hasDuplicates dice si algún nombre sale dos veces.

## Archivos de partida

- `Main.java`

Escribe tu respuesta en `Main.java`. Para probarla, ejecuta `javac Main.java` y después `java Main`.
