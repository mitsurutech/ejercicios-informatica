# Tablas de dos dimensiones: ejercicio `sumas-en-tablas`

> **Lección:** Tablas de dos dimensiones, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Completa los cuatro métodos con una tabla de números. El primero suma una fila. El segundo suma una columna. El tercero suma toda la tabla. El cuarto devuelve el número más grande. Recuerda: primero la fila y después la columna.

## Archivos de partida

- `Main.java`

Escribe tu respuesta en `Main.java`. Para probarla, ejecuta `javac Main.java` y después `java Main`.
