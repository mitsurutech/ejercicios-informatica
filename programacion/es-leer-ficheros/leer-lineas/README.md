# Leer ficheros de texto: ejercicio `leer-lineas`

> **Lección:** Leer ficheros de texto, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Cada método recibe un Scanner, igual que si leyera un fichero. countLines cuenta las líneas. sumNumbers suma las líneas que son números y se salta las demás. firstWith devuelve la primera línea que contiene una palabra. bestStudent lee líneas como Ana;8 y devuelve el nombre de la nota más alta.

## Archivos de partida

- `Main.java`

Escribe tu respuesta en `Main.java`. Para probarla, ejecuta `javac Main.java` y después `java Main`.
