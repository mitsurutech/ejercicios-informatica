# Atributos privados: ejercicio `nota-de-examen`

> **Lección:** Atributos privados, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

La clase Grade guarda una nota de 0 a 10 en un atributo privado. Completa getMark, setMark y result. setMark solo guarda la nota si es válida y dice si la ha guardado. result escribe Aprobado si la nota es 5 o más.

## Archivos de partida

- `Main.java`

Escribe tu respuesta en `Main.java`. Para probarla, ejecuta `javac Main.java` y después `java Main`.
