# Repetir con for: ejercicio `cuatro-for`

> **Lección:** Repetir con for, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Completa los cuatro métodos con un for. El primero escribe la tabla de multiplicar de un número hasta el 10. El segundo suma todos los números entre dos valores, los dos incluidos. El tercero suma los pares: avanza de dos en dos. El cuarto escribe una cuenta atrás con espacios.

## Archivos de partida

- `Main.java`

Escribe tu respuesta en `Main.java`. Para probarla, ejecuta `javac Main.java` y después `java Main`.
