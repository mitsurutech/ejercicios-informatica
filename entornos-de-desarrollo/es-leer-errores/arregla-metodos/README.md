# Leer los errores: ejercicio `arregla-metodos`

> **Lección:** Leer los errores, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Este programa tiene errores. Dos son de compilación y uno solo aparece al ejecutar. Arregla un fallo cada vez. El tercer método debe devolver 0 si no hay partidos, y no fallar.

## Archivos de partida

- `Main.java`

Escribe tu respuesta en `Main.java`. Para probarla, ejecuta `javac Main.java` y después `java Main`.
