# Qué es JSON: ejercicio `tus-datos-en-json`

> **Lección:** Qué es JSON, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Escribe tus datos en JSON. 1. Escribe tu nombre en `name` y tu edad en `age`, sin comillas. 2. Añade una clave `city` con tu ciudad. 3. Añade una clave `hobbies` con una lista de dos aficiones. 4. Añade una clave `hasPhone` con `true` o `false`. Si sale en verde, tu JSON es correcto.

## Archivos de partida

- `index.html`
- `style.css`
- `script.js`

Abre `index.html` en un navegador. Cambia `index.html`, `style.css` y `script.js` y recarga la página para ver el resultado.
