# Qué es una página web: ejercicio `arregla-la-carta`

> **Lección:** Qué es una página web, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Esta carta de un bar tiene un problema. A las etiquetas les falta el cierre. 1. Cierra el título con `</h1>`. 2. Cierra cada párrafo con `</p>`. 3. Añade un párrafo más con otro producto y su precio.

## Archivos de partida

- `index.html`
- `style.css`
- `script.js`

Abre `index.html` en un navegador. Cambia `index.html`, `style.css` y `script.js` y recarga la página para ver el resultado.
