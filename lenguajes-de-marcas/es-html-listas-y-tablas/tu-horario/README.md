# Listas y tablas: ejercicio `tu-horario`

> **Lección:** Listas y tablas, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Completa tu horario de clase. 1. Añade la celda del martes a la fila de las 8:00. 2. Añade dos filas más, para las 9:00 y las 10:00. 3. Cada fila debe tener tres celdas, como la cabecera. 4. Debajo de la tabla escribe una lista con puntos de lo que llevas a clase.

## Archivos de partida

- `index.html`
- `style.css`
- `script.js`

Abre `index.html` en un navegador. Cambia `index.html`, `style.css` y `script.js` y recarga la página para ver el resultado.
