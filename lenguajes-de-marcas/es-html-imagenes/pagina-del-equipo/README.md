# Imágenes y texto alternativo: ejercicio `pagina-del-equipo`

> **Lección:** Imágenes y texto alternativo, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

En esta página hay un balón sin descripción y demasiado grande. 1. Añade un atributo `alt` que describa el balón. 2. Añade `width="120"` para hacerlo más pequeño. 3. Añade otro párrafo con el nombre de tu equipo favorito. 4. Pon una segunda imagen con `src="escudo.png"` y un `alt` que diga "Escudo de mi equipo". Esa imagen no existe, así que verás el texto alt.

## Archivos de partida

- `index.html`
- `style.css`
- `script.js`

Abre `index.html` en un navegador. Cambia `index.html`, `style.css` y `script.js` y recarga la página para ver el resultado.
