# Títulos, párrafos y enlaces: ejercicio `web-del-club`

> **Lección:** Títulos, párrafos y enlaces, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Completa la web del club. 1. Añade un título `h2` que diga "Horario". 2. Debajo escribe un párrafo con el horario de entrenamiento. 3. Añade otro `h2` que diga "Más información". 4. Escribe un párrafo con un enlace a una web que te guste. Pon el texto del enlace entre las etiquetas.

## Archivos de partida

- `index.html`
- `style.css`
- `script.js`

Abre `index.html` en un navegador. Cambia `index.html`, `style.css` y `script.js` y recarga la página para ver el resultado.
