# Formularios: ejercicio `termina-el-pedido`

> **Lección:** Formularios, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

El pedido del recreo está a medias. 1. Añade dos opciones más al menú, como "Bocadillo de jamón" y "Zumo". 2. Añade un campo de tipo `number` con su `label` que diga "Cuántos". Dale `id` y `name` iguales, por ejemplo `amount`. 3. Haz obligatorio el campo del nombre con `required`. 4. Añade un `placeholder` al campo del nombre.

## Archivos de partida

- `index.html`
- `style.css`
- `script.js`

Abre `index.html` en un navegador. Cambia `index.html`, `style.css` y `script.js` y recarga la página para ver el resultado.
