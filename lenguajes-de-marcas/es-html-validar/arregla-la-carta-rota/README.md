# Validar una página: ejercicio `arregla-la-carta-rota`

> **Lección:** Validar una página, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Esta carta tiene varios errores. Arréglalos todos. Busca: un cierre que no coincide, una etiqueta sin cerrar, comillas sin cerrar, una imagen sin `alt` y etiquetas mal anidadas. Después busca el siguiente.

## Archivos de partida

- `index.html`
- `style.css`
- `script.js`

Abre `index.html` en un navegador. Cambia `index.html`, `style.css` y `script.js` y recarga la página para ver el resultado.
