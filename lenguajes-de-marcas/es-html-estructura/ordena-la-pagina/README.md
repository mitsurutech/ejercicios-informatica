# Estructura de una página: ejercicio `ordena-la-pagina`

> **Lección:** Estructura de una página, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Esta página está hecha solo con `div`, y un lector de pantalla no entiende nada. 1. Cambia el primer `div` de dentro por `header`. 2. Cambia el segundo por `nav`. 3. Cambia el tercero por `main`. 4. Cambia el cuarto por `footer`. 5. El `div` de fuera puedes dejarlo: agrupa las cuatro zonas. Recuerda cambiar la etiqueta de apertura y la de cierre.

## Archivos de partida

- `index.html`
- `style.css`
- `script.js`

Abre `index.html` en un navegador. Cambia `index.html`, `style.css` y `script.js` y recarga la página para ver el resultado.
