# Recibir un formulario: ejercicio `pedido-seguro`

> **Lección:** Recibir un formulario, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Completa dos funciones para el formulario de un bar. orderText recibe los datos del formulario en un array con los campos name y dish, y devuelve una línea como esta: Pedido de Ana: tortilla. Quita los espacios de los lados con trim. Si falta el nombre, usa "visitante". Si falta el plato, usa "ninguno". Escapa los dos datos con htmlspecialchars. searchLink crea el enlace de una búsqueda: con "tortilla" devuelve buscar.php?q=tortilla. Usa urlencode para el término.

## Archivos de partida

- `main.php`

Escribe tu respuesta en `main.php`. Para probarla, ejecuta `php main.php`.
