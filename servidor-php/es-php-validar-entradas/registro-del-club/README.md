# No te fíes del usuario: ejercicio `registro-del-club`

> **Lección:** No te fíes del usuario, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

El club de ajedrez abre sus inscripciones. Completa dos funciones. field recibe un array y el nombre de un campo. Devuelve el texto sin espacios a los lados. Si el campo no existe, o no es un texto, devuelve una cadena vacía. validateSignup comprueba name, email y age, siempre con field. El nombre no puede quedar vacío y tiene como máximo 30 letras. El correo tiene que ser válido. La edad debe ser un número entero entre 14 y 99. La función devuelve un array con un mensaje por cada campo que falla, con el nombre del campo como clave y en este orden: name, email, age. Si todo está bien, devuelve un array vacío.

## Archivos de partida

- `main.php`

Escribe tu respuesta en `main.php`. Para probarla, ejecuta `php main.php`.
