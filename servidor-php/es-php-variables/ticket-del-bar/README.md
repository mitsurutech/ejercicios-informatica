# Variables en PHP: ejercicio `ticket-del-bar`

> **Lección:** Variables en PHP, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Vas a preparar el ticket de un bar. En cada café pagas 1,50 euros. Completa las tres funciones.

fullName une el nombre y el apellido con un espacio. totalPrice multiplica los cafés por el precio de cada uno. receipt devuelve un texto como este: Ana: 3 cafés, total 4,50 euros. Para el total usa number_format con dos decimales, coma decimal y punto de miles.

## Archivos de partida

- `main.php`

Escribe tu respuesta en `main.php`. Para probarla, ejecuta `php main.php`.
