# Funciones en PHP: ejercicio `tres-funciones`

> **Lección:** Funciones en PHP, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Completa tres funciones. withVat devuelve el precio con IVA: precio por (100 más el porcentaje), entre 100. Si no se dice el porcentaje, usa 10. greet devuelve un saludo con este formato: Hola, Marta! Si no se dice el saludo, usa "Hola". isEven dice si un número es par: devuelve true o false. Fíjate: en el esqueleto faltan los valores por defecto, y tienes que añadirlos.

## Archivos de partida

- `main.php`

Escribe tu respuesta en `main.php`. Para probarla, ejecuta `php main.php`.
