# Tu primer script en PHP: ejercicio `menu-del-dia`

> **Lección:** Tu primer script en PHP, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Vas a escribir el menú del día de un bar. La función showMenu ya está creada y vacía. Dentro de ella escribe cuatro echo, uno por línea, con este texto exacto:

Menú del día
Primero: lentejas
Segundo: tortilla
Postre: fruta

Al final de cada echo pon \n para saltar de línea. No toques las últimas líneas del fichero.

## Archivos de partida

- `main.php`

Escribe tu respuesta en `main.php`. Para probarla, ejecuta `php main.php`.
