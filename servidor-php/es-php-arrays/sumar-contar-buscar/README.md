# Arrays en PHP: ejercicio `sumar-contar-buscar`

> **Lección:** Arrays en PHP, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Completa tres funciones. sumOf suma todos los números de una lista: con [4, 6, 10] devuelve 20. countPassed cuenta cuántas notas son un aprobado, es decir, 5 o más: con [4, 5, 9, 2] devuelve 2. priceOf busca el precio de un plato en la carta, que es un array con nombre.

## Archivos de partida

- `main.php`

Escribe tu respuesta en `main.php`. Para probarla, ejecuta `php main.php`.
