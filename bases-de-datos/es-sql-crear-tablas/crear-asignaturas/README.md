# Crear tablas: ejercicio `crear-asignaturas`

> **Lección:** Crear tablas, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Ya existe la tabla students. Crea una tabla nueva, subjects, con tres columnas: id (clave primaria), name (texto que no puede quedar vacío) y hours (número entero de horas a la semana). Añade Matemáticas con 4 horas y Lengua con 3 horas. Termina con un SELECT para ver la tabla. La consulta de partida crea la tabla sin la columna hours.

## Archivos de partida

- `schema.sql`
- `query.sql`

Crea la tabla con `schema.sql`, escribe tu respuesta en `query.sql` y ejecútala en cualquier herramienta SQLite o SQL.
