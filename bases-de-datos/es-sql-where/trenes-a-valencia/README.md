# Filtrar con WHERE: ejercicio `trenes-a-valencia`

> **Lección:** Filtrar con WHERE, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Una estación guarda sus trenes en la tabla trains. La consulta de partida enseña todos los trenes a Valencia. Añade una segunda condición con AND para que salgan solo los que cuestan menos de 25 euros.

## Archivos de partida

- `schema.sql`
- `query.sql`

Crea la tabla con `schema.sql`, escribe tu respuesta en `query.sql` y ejecútala en cualquier herramienta SQLite o SQL.
