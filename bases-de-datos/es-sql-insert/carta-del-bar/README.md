# Añadir filas: ejercicio `carta-del-bar`

> **Lección:** Añadir filas, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

La carta del bar está en la tabla snacks. La consulta de partida solo la muestra. Añade una palmera de chocolate que cuesta 1.8 euros, sin escribir el id. Después deja un SELECT al final para ver la carta con la fila nueva.

## Archivos de partida

- `schema.sql`
- `query.sql`

Crea la tabla con `schema.sql`, escribe tu respuesta en `query.sql` y ejecútala en cualquier herramienta SQLite o SQL.
