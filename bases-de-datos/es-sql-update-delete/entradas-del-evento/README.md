# Cambiar y borrar filas: ejercicio `entradas-del-evento`

> **Lección:** Cambiar y borrar filas, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

La tabla tickets guarda las entradas de varios eventos. El concierto de verano sube su entrada a 12 euros. Y hay que borrar los eventos con estado cancelado. La consulta de partida solo muestra la tabla. Escribe el UPDATE, escribe el DELETE y deja un SELECT al final.

## Archivos de partida

- `schema.sql`
- `query.sql`

Crea la tabla con `schema.sql`, escribe tu respuesta en `query.sql` y ejecútala en cualquier herramienta SQLite o SQL.
