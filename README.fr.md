# Exercices d’informatique en espagnol pour les 16-18 ans : programmation avec code de départ

[English](README.md) | [Français](README.fr.md) | [Español](README.es.md) | [日本語](README.ja.md) | [Deutsch](README.de.md)

Des exercices d’informatique gratuits, écrits en espagnol pour les élèves de 16 à 18 ans : 79 exercices de programmation, en Node.js, Java, PHP, SQL et pages web (HTML, CSS, JavaScript). Chacun a un énoncé en mots simples et du code de départ.

[Aperçu gratuit du cours (en espagnol)](https://mitsurutech.co.uk/resources/course/es)

## Ce que contient ce dépôt

Chaque dossier est un exercice de notre cours d’informatique en espagnol. Il contient un README qui dit quoi faire, et les fichiers de départ pour travailler. Les dossiers sont rangés par chapitre, puis par leçon. Utilise ton éditeur habituel. Les exercices eux-mêmes, leurs README et les commentaires du code sont en espagnol ; la liste ci-dessous donne le titre de chaque leçon en français.

## Comment l’utiliser

1. Choisis un exercice dans la liste ci-dessous et ouvre son dossier.
2. Lis son README, puis écris ton code dans les fichiers de départ.
3. Tu es bloqué ? Le cours complet explique chaque idée pas à pas : regarde l’aperçu gratuit du cours.

Les tests cachés et les corrigés ne sont pas ici. Ils restent dans le cours complet, où un enseignant peut donner un exercice, le corriger et faire un retour à ses élèves.
