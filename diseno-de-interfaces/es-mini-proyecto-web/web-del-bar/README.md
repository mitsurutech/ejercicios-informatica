# Mini proyecto: la web del bar: ejercicio `web-del-bar`

> **Lección:** Mini proyecto: la web del bar, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Termina la web del bar Casa Pepe. En el CSS tienes seis notas con lo que hacer. 1. Pon la cabecera en flex, con el menú a la derecha. 2. Pon los platos en una cuadrícula de tres columnas con gap. 3. Da a cada plato un relleno, un borde y un fondo suave. 4. Da al aviso un color con buen contraste. 5. Da al pie fondo oscuro y letras claras. 6. Añade una media query para 600px o menos que ponga los platos en una columna.

## Archivos de partida

- `index.html`
- `style.css`
- `script.js`

Abre `index.html` en un navegador. Cambia `index.html`, `style.css` y `script.js` y recarga la página para ver el resultado.
