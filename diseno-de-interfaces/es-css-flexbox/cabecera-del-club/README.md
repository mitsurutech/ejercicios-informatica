# Colocar con flexbox: ejercicio `cabecera-del-club`

> **Lección:** Colocar con flexbox, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Termina la página del club de lectura. 1. Pon la cabecera header en flex, con el título a la izquierda y el menú a la derecha. 2. Centra el título y el menú en vertical. 3. Pon el menú nav también en flex, con un gap de 16px. 4. Centra la nota en el medio de la zona .stage.

## Archivos de partida

- `index.html`
- `style.css`
- `script.js`

Abre `index.html` en un navegador. Cambia `index.html`, `style.css` y `script.js` y recarga la página para ver el resultado.
