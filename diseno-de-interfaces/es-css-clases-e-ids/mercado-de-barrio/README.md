# Clases e identificadores: ejercicio `mercado-de-barrio`

> **Lección:** Clases e identificadores, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Termina la página del mercado. 1. Añade la clase offer a dos párrafos. 2. Escribe en el CSS la regla .offer con color rojo y letra en negrita. 3. Pon un id a la primera fruta de la lista y escribe su regla con #. 4. Envuelve una palabra de un párrafo en span con otra clase y dale color.

## Archivos de partida

- `index.html`
- `style.css`
- `script.js`

Abre `index.html` en un navegador. Cambia `index.html`, `style.css` y `script.js` y recarga la página para ver el resultado.
