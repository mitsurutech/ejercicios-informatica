# Primeros estilos: ejercicio `carta-del-bar`

> **Lección:** Primeros estilos, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Da estilo a esta carta. 1. Pon el fondo de la página de un color suave. 2. Cambia el tipo de letra de toda la página con body. 3. Centra el título h1 y dale otro color. 4. Pon los párrafos con letra de 18px. Usa al menos cuatro reglas.

## Archivos de partida

- `index.html`
- `style.css`
- `script.js`

Abre `index.html` en un navegador. Cambia `index.html`, `style.css` y `script.js` y recarga la página para ver el resultado.
