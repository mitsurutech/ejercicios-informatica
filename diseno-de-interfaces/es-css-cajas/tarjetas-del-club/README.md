# Todo es una caja: ejercicio `tarjetas-del-club`

> **Lección:** Todo es una caja, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Dibuja las tres tarjetas del club. 1. Escribe la regla .card. 2. Dale un ancho de 220px y un relleno de 15px. 3. Ponle un borde de 2px, continuo y de un color. 4. Separa las tarjetas con un margen de 10px. 5. Usa box-sizing: border-box y un fondo suave.

## Archivos de partida

- `index.html`
- `style.css`
- `script.js`

Abre `index.html` en un navegador. Cambia `index.html`, `style.css` y `script.js` y recarga la página para ver el resultado.
