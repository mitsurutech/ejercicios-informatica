# Páginas para móvil y ordenador: ejercicio `carta-adaptable`

> **Lección:** Páginas para móvil y ordenador, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

La carta del bar tiene tres columnas. En el móvil se ven muy estrechas. 1. Escribe una media query para pantallas de 600px o menos. 2. Dentro, pon .columns con flex-direction: column. 3. Dentro, haz que .col mida el 100% de ancho. 4. Cambia el número 600px por 2000px para ver el diseño de móvil. Después déjalo en 600px.

## Archivos de partida

- `index.html`
- `style.css`
- `script.js`

Abre `index.html` en un navegador. Cambia `index.html`, `style.css` y `script.js` y recarga la página para ver el resultado.
