# Cuadrículas con grid: ejercicio `menu-de-la-semana`

> **Lección:** Cuadrículas con grid, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Termina el menú de la semana. 1. Convierte .week en una cuadrícula de tres columnas iguales. 2. Deja un gap de 12px entre las cajas. 3. Haz que el título .title ocupe las tres columnas. 4. Haz que el plato .special ocupe dos columnas.

## Archivos de partida

- `index.html`
- `style.css`
- `script.js`

Abre `index.html` en un navegador. Cambia `index.html`, `style.css` y `script.js` y recarga la página para ver el resultado.
