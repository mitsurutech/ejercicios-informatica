# Colores y letras legibles: ejercicio `cartel-legible`

> **Lección:** Colores y letras legibles, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Este cartel se lee mal. 1. Cambia el color de las letras a un gris oscuro, como #333333. 2. Sube el tamaño del texto a 1rem como mínimo. 3. Pon el título h1 en un color con buen contraste, por ejemplo #0b3d91. 4. Arregla el color del precio.

## Archivos de partida

- `index.html`
- `style.css`
- `script.js`

Abre `index.html` en un navegador. Cambia `index.html`, `style.css` y `script.js` y recarga la página para ver el resultado.
