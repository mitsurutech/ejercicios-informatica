# Informatikübungen auf Spanisch für 16- bis 18-Jährige: Programmieren mit Startcode

[English](README.md) | [Français](README.fr.md) | [Español](README.es.md) | [日本語](README.ja.md) | [Deutsch](README.de.md)

Kostenlose Informatikübungen, auf Spanisch geschrieben für Schülerinnen und Schüler von 16 bis 18 Jahren: 79 Programmierübungen in Node.js, Java, PHP, SQL und Webseiten (HTML, CSS und JavaScript). Jede hat eine Aufgabenstellung in einfachen Worten und Startcode.

[Kostenlose Vorschau des Kurses (auf Spanisch)](https://mitsurutech.co.uk/resources/course/es)

## Was dieses Repository enthält

Jeder Ordner ist eine Übung aus unserem Informatikkurs auf Spanisch. Er enthält eine README, die sagt, was zu tun ist, und die Startdateien zum Arbeiten. Die Ordner sind nach Kapitel und nach Lektion geordnet. Verwenden Sie Ihren gewohnten Editor. Die Übungen selbst, ihre READMEs und der Code sind auf Spanisch; die Liste unten nennt den Titel jeder Lektion auf Deutsch.

## So verwenden Sie es

1. Wählen Sie eine Übung aus der Liste unten und öffnen Sie ihren Ordner.
2. Lesen Sie ihre README und schreiben Sie Ihren Code in die Startdateien.
3. Sie kommen nicht weiter? Der vollständige Kurs erklärt jede Idee Schritt für Schritt: Sehen Sie sich die kostenlose Vorschau des Kurses an.

Die verborgenen Tests und die Musterlösungen sind nicht hier. Sie bleiben im vollständigen Kurs, wo eine Lehrkraft eine Übung stellen, bewerten und ihren Schülerinnen und Schülern Rückmeldung geben kann.
