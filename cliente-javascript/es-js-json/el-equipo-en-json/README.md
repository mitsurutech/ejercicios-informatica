# JSON en JavaScript: ejercicio `el-equipo-en-json`

> **Lección:** JSON en JavaScript, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Un equipo se guarda como texto JSON: una lista de jugadores con name y goals. Completa cuatro funciones. playerToJson convierte un jugador en texto. playersFromJson lee la lista y se calla si el texto está roto. totalGoals suma los goles. addPlayer añade un jugador.

## Archivos de partida

- `main.js`

Escribe tu respuesta en `main.js`. Para probarla, añade unas líneas `console.log(...)` al final y ejecuta `node main.js`.
