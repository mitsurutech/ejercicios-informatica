# Tu primer script: ejercicio `tarjeta-del-jugador`

> **Lección:** Tu primer script, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Haz la tarjeta de un jugador. 1. Crea una constante playerName con tu nombre y otra team con tu equipo. 2. Crea las variables age y goals. 3. Sube age y goals una unidad cada una. 4. Quita las dos barras de la última línea para que la tarjeta salga en la página.

## Archivos de partida

- `index.html`
- `style.css`
- `script.js`

Abre `index.html` en un navegador. Cambia `index.html`, `style.css` y `script.js` y recarga la página para ver el resultado.
