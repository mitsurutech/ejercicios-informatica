# Funciones: ejercicio `cuatro-funciones`

> **Lección:** Funciones, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Completa cuatro funciones. busFare da el precio del viaje según la edad. average calcula la media de tres notas. isEven dice si un número es par. makeLabel junta un nombre y un equipo en un texto. Cada función debe terminar en return.

## Archivos de partida

- `main.js`

Escribe tu respuesta en `main.js`. Para probarla, añade unas líneas `console.log(...)` al final y ejecuta `node main.js`.
