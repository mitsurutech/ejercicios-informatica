# Mini proyecto: lista de tareas: ejercicio `lista-de-tareas`

> **Lección:** Mini proyecto: lista de tareas, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Termina la lista de tareas. Los pasos están en los comentarios. 1. Pinta las tareas y marca las hechas con un clic. 2. Añade tareas con el formulario. 3. Pon un botón Borrar en cada tarea. 4. Cuenta las que faltan. El paso 5 es un extra.

## Archivos de partida

- `index.html`
- `style.css`
- `script.js`

Abre `index.html` en un navegador. Cambia `index.html`, `style.css` y `script.js` y recarga la página para ver el resultado.
