# Cambiar la página: ejercicio `tienda-del-barrio`

> **Lección:** Cambiar la página, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Arregla la página de la tienda con JavaScript. Los pasos están en los comentarios. 1. Cambia el título. 2. Cambia el precio. 3. Pon la clase sale al primer producto. 4. Añade las tres frutas nuevas con un bucle.

## Archivos de partida

- `index.html`
- `style.css`
- `script.js`

Abre `index.html` en un navegador. Cambia `index.html`, `style.css` y `script.js` y recarga la página para ver el resultado.
