# Pedir datos con fetch: ejercicio `el-menu-del-dia`

> **Lección:** Pedir datos con fetch, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Un servidor da el menú del día como una lista de productos con name y price. Las funciones reciben el fetcher, que hace de fetch, y la dirección. Completa cuatro funciones. loadMenu pide los datos y devuelve una lista vacía si algo falla. Las otras tres usan loadMenu.

## Archivos de partida

- `main.js`

Escribe tu respuesta en `main.js`. Para probarla, añade unas líneas `console.log(...)` al final y ejecuta `node main.js`.
