# Decidir en JavaScript: ejercicio `la-nota-del-examen`

> **Lección:** Decidir en JavaScript, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Convierte una nota en una palabra. 1. Escribe un if con varias ramas dentro del script. 2. Guarda la palabra en message. 3. Si la nota es menor que 0 o mayor que 10, el mensaje es "Nota no válida".

## Archivos de partida

- `index.html`
- `style.css`
- `script.js`

Abre `index.html` en un navegador. Cambia `index.html`, `style.css` y `script.js` y recarga la página para ver el resultado.
