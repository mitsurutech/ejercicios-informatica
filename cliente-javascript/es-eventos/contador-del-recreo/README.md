# Eventos: clics y teclas: ejercicio `contador-del-recreo`

> **Lección:** Eventos: clics y teclas, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

Termina el contador de bocadillos. Hay tres botones y los pasos están en los comentarios. 1. Uno más suma uno. 2. Uno menos resta uno, pero nunca baja de cero. 3. Vaciar vuelve a cero.

## Archivos de partida

- `index.html`
- `style.css`
- `script.js`

Abre `index.html` en un navegador. Cambia `index.html`, `style.css` y `script.js` y recarga la página para ver el resultado.
