## Qué hay que hacer

Hoy el grupo ha pedido 4 bocadillos y 3 zumos. Haz el recibo. 1. Calcula sandwichTotal, juiceTotal y total. 2. Escribe en la página una frase con una plantilla de texto y toFixed(2).

## Archivos de partida

- `index.html`
- `style.css`
- `script.js`

Abre `index.html` en un navegador. Cambia `index.html`, `style.css` y `script.js` y recarga la página para ver el resultado.
