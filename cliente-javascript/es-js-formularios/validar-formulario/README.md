# Comprobar un formulario: ejercicio `validar-formulario`

> **Lección:** Comprobar un formulario, en la [vista previa gratuita del curso](https://mitsurutech.co.uk/resources/course/es)

## Qué hay que hacer

El formulario del torneo pide nombre, edad y correo. Completa cuatro funciones. Cada una devuelve un mensaje de error, o un texto vacío si el dato vale. Los mensajes exactos están en los comentarios. checkForm junta todos los errores en una lista.

## Archivos de partida

- `main.js`

Escribe tu respuesta en `main.js`. Para probarla, añade unas líneas `console.log(...)` al final y ejecuta `node main.js`.
