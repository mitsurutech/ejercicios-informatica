# スペイン語で学ぶ16〜18歳向けの情報演習：スターターコード付きのプログラミング

[English](README.md) | [Français](README.fr.md) | [Español](README.es.md) | [日本語](README.ja.md) | [Deutsch](README.de.md)

16歳から18歳の生徒のためにスペイン語で書いた、無料の情報の演習です。Node.js、Java、PHP、SQL、Webページ（HTML、CSS、JavaScript）のプログラミング演習が79問あり、どれも、やさしい言葉の問題文とスターターコードが付いています。

[無料のコースプレビュー（スペイン語）](https://mitsurutech.co.uk/resources/course/es)

## このリポジトリの中身

それぞれのフォルダは、スペイン語の情報コースの演習1問です。何をするかを書いたREADMEと、取りかかるためのスターターファイルが入っています。フォルダは、章ごと、レッスンごとに分けてあります。いつものエディタで取り組んでください。演習そのもの、README、コードのコメントはスペイン語です。下の一覧では、各レッスンの題名を日本語で示しています。

## 使い方

1. 下の一覧から演習を選んで、そのフォルダを開きます。
2. READMEを読んで、スターターファイルにコードを書きます。
3. 行きづまったら、完全版のコースが、一つずつ順に説明しています。無料のコースプレビューを見てください。

隠しテストと模範解答はここにはありません。先生が演習を出し、採点し、生徒にコメントを返せる、完全版のコースにあります。
